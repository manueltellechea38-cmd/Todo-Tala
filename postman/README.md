# Postman - Todo Tala

Esta carpeta se usará para guardar y compartir los archivos exportados de Postman del proyecto.

Más adelante se guardarán aquí:

- TodoTala.postman_collection.json
- TodoTala.postman_environment.json

La colección contendrá las pruebas de las APIs de productos, usuarios, comercios, empleados, categorías, promociones, carrito, pedidos y login.

Antes de conectar el frontend, cada endpoint debe probarse manualmente en Postman.

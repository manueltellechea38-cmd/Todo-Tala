# Postman - Todo Tala 1.0

Importar:

TodoTala.postman_collection.json

La colección utiliza:

base_url = http://localhost:3000

y la variable:

token

Primero ejecutar Login Cliente o Login Jefe.

Copiar el token recibido a la variable token.

Después se pueden probar las APIs protegidas según el rol correspondiente.

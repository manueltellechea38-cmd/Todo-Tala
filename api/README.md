# API Todo Tala

Esta carpeta se usará para las APIs en PHP del proyecto Todo Tala.

La estructura se mantendrá simple, siguiendo el material de clase:

- conexion.php
- productos.php
- usuarios.php
- comercios.php
- empleados.php
- categorias.php
- promociones.php
- carrito.php
- pedidos.php
- login.php

Cada archivo PHP representará un recurso de la API y se probará primero con Postman antes de conectarlo al frontend.

No subir contraseñas reales de MySQL al repositorio.

# Todo Tala - Maqueta digital

Sitio web simple para presentar las principales pantallas del proyecto Todo Tala junto con su nombre y una breve descripción.

## Contenido

- Acceso: inicio de sesión y registro.
- Cliente: inicio, catálogo, búsqueda, detalle de producto, carrito, pedidos y perfil.
- Jefe/comercio: panel, productos, promociones, empleados y pedidos recibidos.
- Modo oscuro por defecto y botón para cambiar a modo claro.
- Las capturas se pueden ampliar haciendo clic sobre ellas.

Las imágenes se cargan desde la carpeta pública de Google Drive del proyecto.
